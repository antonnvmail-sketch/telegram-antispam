# Изменения

## После выпуска 1.0.3 — документация

- 30 октября 2026: исправлен ошибочный заголовок раздела 1.0.2 в русском и английском README. Описание сохранено, история 1.0.3 и 1.0.2 снова разделена. Программный код не менялся.

## 1.0.3 — 30 октября 2026

- Кнопки ручной модерации, отметка ошибочного удаления и отдельное хранение обратной связи без автоматического обучения.
- `/review`, `/stat`, `/stat_export`, `/review_stats` и обновлённая помощь. Месячные счётчики по МСК не выдаются за точность модели.
- Компактные карточки с названием чата, переходом, результатом действия и понятными ошибками; защита привязок/повторов, срок кнопок 24 часа.
- Защита от второго процесса и необязательная настройка автозапуска, контроля зависания, связи с Telegram и прав удаления.
- Сохранены DRY_RUN=true по умолчанию, блокировка кнопок в пробном режиме, прежняя классификация и пороги. Рабочие данные и модель автора не включены.
- Проведено тестирование.


## 1.0.2 — 28 октября 2026

- Добавлен счётчик новых примеров после обучения в `/add_spam`, `/add_ham` и `/status`. Учитывает импорт и повторные примеры, сохраняется после перезапуска; для старых моделей без истории показано «неизвестно» до переобучения.
- Метаданные обучения сохраняются вместе с моделью; файл заменяется только после завершения записи, при ошибке сохраняется предыдущий файл.
- Добавлен английский README и ссылка на него в русском README. Качество английской модерации не заявляется.
- Проведено тестирование.

- Упрощён состав самостоятельного бота: удалены неиспользуемые дополнительные компоненты, их команды, настройки и вспомогательная миграция. Сохранены обучение, фильтрация, журнал решений, уведомления и пробный режим. Существующие пользовательские таблицы не удаляются.

## После выпуска 1.0.1 — документация

- Упрощены публичные формулировки о тестировании в README и заметках выпуска: без количества тестов и перечисления систем. Код не менялся.

- По просьбе автора из README, публичной истории изменений и заметок GitHub-релиза убраны описания дополнительных компонентов и интеграций. Настройки и код сохранены. Первоначально правки касались только основной ветки; затем включены в комплект выпуска, как указано выше.

## 1.0.1 — 28 октября 2026

- Разделены решение, удаление, результат Telegram, журнал и уведомления. Ошибки этапов различаются, таймаут не считается успешным удалением; автоматических повторов нет.
- Общая функция фильтра и `/test_spam`; журнал P(spam), причины, порогов, версии политики, UUID/времени и SHA256 загруженной модели/входа. Модель и её хеш загружаются из одинаковых байтов.
- Идемпотентная миграция 002 добавляет moderation_decisions с source=filter/test_spam и dry_run=0/1. Старая история не переписывается; для технической таблицы без dry_run колонка добавляется с default=0.
- Сохранены DRY_RUN=true, демонстрационные данные, проверка конфигурации до создания рабочих файлов и разбор `/command@bot`.
- `/status` показывает версию бота/модели; диагностика отображает причину/пороги/версию и результат сохранения, не удаляя и не рассылая сообщение.
- Перед выпуском проведено тестирование; результаты доступны в Actions.
- README дополнен обновлением/откатом с сохранением новой истории. Пороги и условия фильтрации сохранены; улучшение независимой точности не заявляется.
- Рабочие данные, токены, БД, модели и закрытые серверные отчёты не публикуются. Публичная версия сохраняет свои безопасные настройки; публикация не развёртывает изменения на авторском сервере.
